# assets

Design sources. Nothing here is loaded at runtime.

- `brand/world-{chain,coin,id}.png` — World's line-art marks. The app loads the
  optimised copies at `miniapp/app/public/brand/illus/*.webp`; these originals ship
  so those can be regenerated.
- `reference/` — World's own data-visualisation style guide, kept as a reference for
  how the Spending panel's bars are drawn. Not used by the app.

The full World brand kit (`Logo.zip`, 12 MB) is deliberately not tracked.
